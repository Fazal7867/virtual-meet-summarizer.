# Virtual Meet Summarizer

A full-stack application designed to process virtual meeting content, generate transcripts, and produce concise summaries using NLP-based text processing.

## 📌 Overview

Virtual Meet Summarizer helps convert meeting content into structured and readable information, reducing the effort required to review lengthy meeting conversations.

The project combines a React-based frontend with a Python backend to handle meeting data, transcription, and summarization workflows.

## ✨ Features

- 🎙️ Meeting audio transcription
- 📝 Automatic meeting summarization
- 🧠 NLP-based text processing
- 📄 Processing of meeting transcripts
- ⚡ React-based frontend interface
- 🔗 Python backend for application logic
- 🧪 Backend testing support
